# Music bed

Drop ONE audio file here (`.mp3` / `.m4a` / `.wav`) and every episode mixes it
under the voiceover at low volume (see `music.volume` in `video/config.json`).

Safest source for a monetized channel: **YouTube Audio Library**
(studio.youtube.com → Audio Library) — tracks there are cleared for YouTube and
won't trigger Content ID. Lo-fi / chill-hop fits the channel's style.

No file here = no music, episodes render voice-only.
